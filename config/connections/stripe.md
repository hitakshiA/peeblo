Stripe's MCP returns customer name, email, phone and metadata as [REDACTED]; match customers on another field (description) and list customers page by page. Amounts are in the currency's smallest unit (37.00 is 3700), in the invoice's or customer's currency: divide by 100 before you say one (amount 2900 is $29.00, never "2,900"). Times are Unix seconds. A call that failed is not an empty result: say it failed, not that there is nothing. For MRR or subscription counts, list active subscriptions page by page and add them up. Not every API operation is offered on the MCP; find one with stripe_api_search before asking anyone to approve a write.
