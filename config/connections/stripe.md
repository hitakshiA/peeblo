Stripe's MCP returns customer name, email, phone and metadata as [REDACTED]; match customers on another field (description) and list customers page by page. Amounts are in the currency's smallest unit (37.00 is 3700), in the invoice's or customer's currency. For MRR or subscription counts, list active subscriptions page by page and add them up. Not every API operation is offered on the MCP; find one with stripe_api_search before asking anyone to approve a write.
